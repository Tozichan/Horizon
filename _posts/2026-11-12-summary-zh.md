### [Google DeepMind 发布 AlphaGenome 2，聚焦细胞层面的疾病根源](https://www.theverge.com/ai-artificial-intelligence/1031524/google-deepmind-alphagenome-2-genetic-ai-model) ⭐️ 8.0/10

Google DeepMind 公布了 AlphaGenome 2，这是其基因组预测 AI 模型 AlphaGenome 的后继版本，目标是模拟 DNA 变化如何影响不同细胞类型，从而帮助理解疾病成因并寻找新疗法。AlphaGenome 于去年发布，而新模型的具体方法、基准测试和验证结果在现有报道中尚未披露，因此其能力目前仍属厂商公布的计划，而非可独立核实的实测结果。

rss · The Verge · 11月11日 15:00

**「背景」** AlphaGenome 是 Google DeepMind 此前发布的基因组预测模型，可接收最长约 100 万个碱基对的 DNA 序列，并预测数千项刻画其调控活性的分子属性；DeepMind 还通过 API 向研究者开放该模型。此次发布的 AlphaGenome 2 是它的后继版本，报道称其重点在于解析 DNA 变化如何在不同细胞类型中产生不同影响。

**「对研究者的影响」** 据 DeepMind 官方博客和《自然》新闻报道，AlphaGenome 2 可预测 DNA 变异在哪些细胞类型中可能发挥作用，从而把单细胞生物学与人类遗传学联系起来。对遗传学和疾病研究者而言，这意味着变异筛选可先按细胞类型缩小范围，再进入实验验证；但现有材料未给出基准数据或独立验证结果，实际预测精度和适用范围仍需以论文或第三方评测为准。

### [谷歌发布 Gemini Decisions API，面向快速多模态封闭式决策](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/) ⭐️ 8.0/10

谷歌发布 Gemini Decisions API，基于新模型 Gemini Decision 1，面向工具选择、策略检查、模型路由等封闭式决策任务。该 API 支持文本、图像、音频、视频和 PDF 输入，单次最多可对 1000 个问题打分并返回概率与置信度，谷歌称端到端延迟约为 150–250 毫秒。定价为每百万输入 tokens 0.10 美元、输出 token 不收费，谷歌称其比 Gemini 3.5 Flash-Lite 方案便宜近 5 倍；目前已在 Google AI Studio 提供。上述延迟、价格和成本对比均为谷歌自述，尚未见到独立验证。

telegram · zaihuapd · 11月12日 00:28

**「背景」** Gemini Decisions API 由谷歌新发布的 Gemini Decision 1 模型驱动，该模型专门用于返回概率与置信度的封闭式决策任务。此前同类需求通常依赖通用模型或语法约束输出，但后者无法直接给出概率；谷歌此次将这一能力单独做成 API，并支持文本、图像、音频、视频和 PDF 输入。

**「对开发者的影响」** 对需要频繁做路由或筛选的开发者而言，按输入 token 计费、输出不收费的定价使“长上下文加大量小问题”的批量打分成本较低；但接入前应自行验证多模态输入下的延迟与准确率，因为现有性能数据来自厂商声明。

**「社区讨论」** 有评论者称自己做的快速评测中，该模型在多种场景下的 Brier 分数比 Jev 低约 4 倍（视任务在 2–6 倍之间），p50 延迟也低 100 毫秒以上，但整套评测成本约为两倍；另一名评论者则认为它比同类的其他决策模型更贵，音频和视频输入是其特定优势。也有人提出疑问：这类模型如何计算概率，以及目前开发者如何在编码工具链中使用决策模型。

### [AWS 发布本地服务模拟器，安全测试范围受限](https://github.com/aws/aws-emulator) ⭐️ 7.0/10

AWS 发布了用于本地测试其服务的模拟器，项目托管在 GitHub 的 aws/aws-emulator 仓库下。根据社区引用的安全页面，该模拟器明确不建议用于测试 IAM 策略与权限边界、基于资源的策略（如存储桶策略）、AWS KMS 密钥策略、跨账户或跨区域访问以及其他安全控制；部分服务虽会评估模拟器内创建的 IAM 用户和角色策略，但行为与 AWS 不一致，且模拟器从不拒绝用其自身密钥签名的请求。目前尚不清楚这是内部练习还是会被长期维护并正式发布的产品。

hackernews · super\_linear · 11月11日 18:21 · [社区讨论](https://news.ycombinator.com/item?id=50456631)

**「背景」** 在 AWS 推出这一本地模拟器之前，开发者主要依靠 LocalStack 等第三方工具在本地模拟 AWS 服务；据外部报道，LocalStack 的社区版已停止免费提供，开始要求认证令牌并冻结免费用户的安全更新，促使社区出现 Floci、LocalEmu 等替代方案。AWS 模拟器本身是一个无图形界面的本地程序，启动后通过环境变量把 AWS CLI 或 SDK 的请求指向其端点，从而在本地运行代码。

**「对使用者的实际影响」** 根据安全页面，该模拟器不能用于验证 IAM 策略与权限边界、基于资源的策略（如存储桶策略）、KMS 密钥策略，以及跨账户或跨区域访问；它也不会像 AWS 那样拒绝用自身密钥签名的请求。因此，依赖这些控制项做安全测试的团队仍需在真实 AWS 环境中验证。社区评论中有人提到已在使用 Floci 配合 Testcontainers，并指出后者同样支持 GCP 和 Azure，可作为替代方案评估。

**「社区讨论」** 有评论者对是否采用持怀疑态度，理由是尚不清楚该项目只是练习还是会真正发布并维护，并称 Floci 配合 Testcontainers 使用体验良好且支持 GCP 和 Azure。另一位评论者引用安全页面指出，模拟器不能用于验证 IAM、资源策略、KMS 及跨账户/跨区域控制。也有自称亚马逊员工的评论者认为，若能做好并持续维护，该工具对需要封闭系统、模拟外部依赖的智能体开发很有价值。

### [Python 核心开发者 Tim Peters 逝世](https://discuss.python.org/t/in-memoriam-tim-peters-1952-2026/110028) ⭐️ 7.0/10

Python 社区发布讣告，纪念核心开发者 Tim Peters（1952–2026）。他以撰写《Python 之禅》（Zen of Python）闻名，该文本可通过 \`python -c &quot;import this&quot;\` 查看。除长期参与 Python 开发外，他还与 Gary Robinson 等人合作，将 Paul Graham 的“A Plan for Spam”一文转化为反垃圾邮件程序 SpamBayes，并参与了《Python Cookbook》第二版的编写。
